# Outils interactifs, microéconomie LSO2

Outils interactifs pour le cours de microéconomie LSO2 (Paris-Dauphine) : chapitre 1, équilibres et optimalités ; chapitre 2, effets externes ; cartes, QCM, générateur d'exercices et lexique pour réviser.

Site : https://marco-faure.github.io/Microeconomie_LSO2/

Pour ajouter un outil, compléter la liste `SITE` en tête de `commun.js` et déposer la page à la racine.
